# 易球经络篇

> 用途：我的易球 · 经络循行三维映像（1.0）的内容蓝本与过程检查素材。本文严格取材于成品代码中「子午流注时辰表 MERIDIAN」与「十二经络循行路径」的既定规则。

## 一、十二经络 · 子午流注时辰表

一个昼夜十二时辰，各有一条经络当令，每经两小时：

| 时辰 | 时段 | 经络 |
|---|---|---|
| 寅 | 03–05 | 肺经 |
| 卯 | 05–07 | 大肠经 |
| 辰 | 07–09 | 胃经 |
| 巳 | 09–11 | 脾经 |
| 午 | 11–13 | 心经 |
| 未 | 13–15 | 小肠经 |
| 申 | 15–17 | 膀胱经 |
| 酉 | 17–19 | 肾经 |
| 戌 | 19–21 | 心包经 |
| 亥 | 21–23 | 三焦经 |
| 子 | 23–01 | 胆经 |
| 丑 | 01–03 | 肝经 |

## 二、循行时辰锚点（三维映像的钟面）

循行按「子 → 丑 → … → 亥」正序推进，起点 0h=24h（子时胆经），每过 2 小时（=1/12 圈）换一经：

- 0h 子胆 → 2h 丑肝 → 4h 寅肺 → 6h 卯大肠 → 8h 辰胃 → 10h 巳脾
- 12h 午心 → 14h 未小肠 → 16h 申膀胱 → 18h 酉肾 → 20h 戌心包 → 22h 亥三焦 → 24h 回到子胆

关键锚点：6h（1/4 圈）= 大肠经；12h（半圈）= 心经；18h（3/4 圈）= 肾经；0h/24h（起点）= 胆经。

## 三、循行路径画法（贴球面）

- 起点：赤道（III 层）上 55/56 卦之间的交汇点，经度 270 = 24h 点 = 0h。
- 横向（沿纬线）每折 +15° 用虚线；纵向（沿经线上下）用实线；在赤道 ↔ 60°N/60°S 之间来回折返，转折只出现在一层（60°S）、三层（赤道）、五层（60°N），途经二/四层。
- 共 12 段对应十二经络；整条路径沿球面转满 360°，回到起点，构成闭合环。
- 折向交替：偶数段先向上（60°N），奇数段先向下（60°S）。

## 四、动态循行规则（1.0 定稿模型）

- 白点（气行头灯）长在球面上，沿循行路径跑动；它跑到球面哪个位置，球就把那一面转到正对观察者——球的转动没有独立转速/方向，只负责"追着白点把它转到正面"。
- 白点跑满一圈 ⇔ 球体恰好追着转满 360°，二者同时回到起点对齐。
- 十二经络均分时间：默认 144 秒/圈，每经 12 秒；可切换 72–288 秒/圈，规律不变。
- 默认交互：打开页面先停在 0h 起点；点击屏幕任意处/任意键才开始；空格暂停/继续；可拖动旋转视角，白点所在面始终正对。
- 十二经络底部图例随循行联动高亮当前时辰。

## 五、消息卦关联（精油卡版）

每个时辰对应一个"消息卦"（十二消息卦体系），在精油卡版中循行到该时辰时，对应的消息卦精油卡会自动放大呈现，卦卡取材自多特瑞官方素材，供学习展示参考。
