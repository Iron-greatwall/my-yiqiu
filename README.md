# 我的易球 · 1.0

易经 × 经络 × 精油 —— 三维映像桌面项目（纯前端 Three.js，两页应用）。

## 里面有什么

- **我的易球（index.html / 我的易球.html）**：易经六十四卦三维球（I–V 层阳爻 + 太极线），叠加**十二经络循行**。子午流注白点长在球面上沿路径跑动，球体无独立转速/方向，只负责把白点所在的那一面转到正对观察者——白点跑满一圈 ⇔ 球体恰好转满 360°，同时回到 0h 起点（子时胆经）。
- **精油卡3D/**：64 卦 ↔ 64 支多特瑞精油的三维展台（桌面多特瑞文案版），卦卡取材多特瑞官方素材；循行到某时辰，对应消息卦精油卡自动放大。精油内容仅供学习展示，非医疗建议。

## 经络篇速览（详见 docs/易球经络篇.md）

- 十二时辰各一经当令：寅肺 → 卯大肠 → 辰胃 → 巳脾 → 午心 → 未小肠 → 申膀胱 → 酉肾 → 戌心包 → 亥三焦 → 子胆 → 丑肝。
- 循行锚点：0h 子胆 → 6h(¼圈) 卯大肠 → 12h(半圈) 午心 → 18h(¾圈) 酉肾 → 24h 归位。
- 路径画法：横向沿纬线每折 +15° 用虚线、纵向经线在赤道↔±60° 用实线，12 段绕球 360° 闭合成环。

## 操作

点击屏幕任意处开始循行；空格 暂停/继续；拖动、滚轮旋转缩放视角；点卦卡查看档案（精油卡版）。

## 本地运行

Three.js 走 ES Module，需通过 http 访问（勿直接双击文件）：

```bash
python3 -m http.server 8000 --bind 0.0.0.0   # 在项目根目录运行
# 主球：   http://localhost:8000/
# 精油卡： http://localhost:8000/精油卡3D/
```
